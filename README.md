# ZERO - Card Game

A browser-based card game built with JavaScript, HTML and CSS. Play against computer-controlled opponents.

Play: https://pavanteja1706.github.io/ZERO-Card-Game/

## Features
- You vs. computer-controlled opponents
- Face-down hands with an initial peek at two cards
- Power cards: peek (9/10), blind swap (J), compare-and-swap (Q)
- Same-rank drop chain
- Rule-based opponent logic (hand-value estimation, declare threshold, swap decisions)
- Round scoring and a final champion screen

## Tech
JavaScript, HTML, CSS (single file, no dependencies)

## Run locally
Open index.html in a browser.
